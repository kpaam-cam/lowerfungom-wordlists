# Supplementary materials for "Areal micro-dynamics as a window onto
Niger-Congo prehistory"

## How to cite

If you use these materials use the DOI of the [particular released version](../../releases/) you use


## Description

These are the analytical outputs and scripts used to generate the analyses in the paper entitled "Areal micro-dynamics as a window onto Niger-Congo prehistory"

The paper makes use of data that is connected to the dataset found here:
https://doi.org/10.5281/zenodo.15814992

The raw data and scripts used to generate some of the materials used for this papaer can be found there.
